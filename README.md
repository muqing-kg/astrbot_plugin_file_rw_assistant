# 文件读写小助手

AstrBot 插件：自动归档聊天中的文件与视频，并向模型提供读取、修改、生成与发送能力，附带 Web 管理面板。

插件 ID：`astrbot_plugin_file_rw_assistant`

## 功能特性

- **自动入库**：群聊与私聊中收到的文件自动归档，保留原文件名，同名文件不覆盖。
- **版本管理**：每次改写生成新版本，历史版本可查看与下载，可设置版本数量上限。
- **内容读取**：文本、Markdown、代码、CSV 直接读取；Word、Excel、PPT、PDF 解析正文；扫描版 PDF 按页渲染后交视觉模型识别；视频按场景切换抽帧（静态画面退回均匀抽帧），内嵌字幕连同时间轴一起交给模型。
- **内容修改**：文本整体替换；Excel、PPT、Word 就地改写并保留原有格式（列宽、公式、母版）；PDF 支持按页提取与按页识图。
- **文件生成**：生成新的 Word、Excel、PPT 或文本文件；也可复制现有文件另存一份再改，格式原样保留。
- **发送回会话**：通过消息平台直接发送；平台不支持时提示文件位置。
- **Web 面板**：文件列表、类型筛选、内容查看（可切历史版本）、下载、删除、分片上传。
- **自动清理**：按保留天数定时清理，超出上限的历史版本自动淘汰。

## 支持的文件类型

| 类别 | 扩展名 |
| --- | --- |
| Word | `.docx` `.doc` |
| Excel | `.xlsx` `.xls` |
| 演示文稿 | `.pptx` `.ppt` |
| PDF | `.pdf` |
| 文本 | `.txt` `.log` |
| Markdown | `.md` `.markdown` |
| 代码 | `.py` `.js` `.ts` `.json` `.yaml` `.yml` `.sh` `.sql` `.html` `.css` `.toml` `.ini` |
| 表格数据 | `.csv` `.tsv` |
| 视频 | `.mp4` `.mov` `.mkv` `.avi` `.webm` |

压缩包、图片、音频不在支持范围内。

## 环境要求

- AstrBot `>=4.16,<5`
- Python 依赖：`python-pptx`、`pypdf`、`pypdfium2`、`yt-dlp`（由 `requirements.txt` 自动安装）
- 视频抽帧与抽音轨需要容器内可执行 `ffmpeg`；听声音还要求所选模型支持音频输入

## 安装

1. 进入 AstrBot 面板 → 插件 → 从仓库安装，填入 `muqing-kg/astrbot_plugin_file_rw_assistant`。
2. 等待依赖安装完成。
3. 刷新插件列表完成加载。

依赖安装完成后需刷新一次插件列表；若依赖尚未就绪即加载，插件会因缺少模块而失败。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
### 存储与清理

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `retention_days` | int | `90` | 文件保留天数，到期自动删除 |
| `max_versions` | int | `20` | 单文件最多保留版本数 |
| `max_file_mb` | int | `200` | 文档单文件上限（MB） |
| `max_video_mb` | int | `2048` | 视频单文件上限（MB） |
| `auto_cleanup` | bool | `true` | 启用到期自动清理 |

### 视频理解

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `video_frame_interval` | float | `4` | 每隔几秒抽一帧，帧数由时长自动算出 |
| `video_max_frames` | int | `24` | 视频最多抽几帧 |
| `video_audio` | bool | `true` | 是否把视频原声一起交给模型 |
| `video_audio_seconds` | int | `300` | 原声最多送多少秒 |
| `video_prompt` | text | 见默认值 | 视频理解提示词 |

### 文档与图片

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `read_max_chars` | int | `8000` | 单次读文档最多返回多少字 |
| `enable_pdf_ocr` | bool | `true` | 扫描版 PDF 转图识别 |
| `vision_prompt` | text | 见默认值 | 图片与文档内嵌图提示词 |
| `summary_prompt` | text | 见默认值 | 长文档摘要提示词 |

### 模型

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `text_model_provider_id` | string | 空 | 长文档压缩使用的模型；留空跟随当前会话模型 |
| `vision_model_provider_id` | string | 空 | 图片与视频识别使用的模型；留空跟随当前会话模型 |

### 发回与链接

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `send_max_mb` | int | `100` | 发回单个文件上限（MB），超限只回面板提示 |
| `video_link_enabled` | bool | `false` | 是否允许解析视频链接；默认关闭，需要时打开 |
| `video_link_cookies` | string | 空 | 需要登录态平台的 cookies（文本或文件路径） |

## 提示词占位符

三段提示词支持占位符，运行时会替换成实际值；写了不认识的花括号会原样保留。

| 配置项 | 可用占位符 |
| --- | --- |
| video_prompt | {title} 文件名、{seconds} 视频时长（秒）、{frames} 实际抽帧数、{audio} 原声「有/无」 |
| vision_prompt | {count} 本次送模型看几张图 |
| summary_prompt | {chars} 待压缩正文的字符数 |

例：这部视频叫《{title}》，时长 {seconds} 秒，我抽了 {frames} 帧，原声：{audio}。说说画面里发生了什么。
## 使用方式

### 通过聊天

收到文件后无需额外操作，插件自动归档并在当轮上下文中提供给模型。常见请求示例：

| 需求 | 示例说法 |
| --- | --- |
| 查找文件 | 「刚才那个表格在哪里」「列出全部 Excel」「昨天谁发的那个文档」 |
| 读取内容 | 「这份 PDF 的主要内容是什么」 |
| 长文档定位 | 「第 30 页讲了什么」「找出所有写着逾期的行」 |
| 识别扫描件 | 「这张扫描件上写了什么」 |
| 修改单元格 | 「把 B2 的值改成 2024」 |
| 修改演示文稿 | 「第 2 页标题换一种说法」 |
| 修改文档 | 「删除第三段」 |
| 处理 PDF | 「只保留第 1 至 3 页」「这几页版式什么样」 |
| 生成文件 | 「生成一份 Word 周报」「做成一张 Excel 表」「做个三页 PPT」 |
| 照格式另存 | 「照这份 PPT 的样式改一份新的」 |
| 发送文件 | 「把这份文件发给我」 |
| 视频内容 | 「这个视频讲了什么」 |
| 视频链接 | 发送链接并询问「这个视频讲什么」 |
| 删除文件 | 在面板中操作（模型无删除权限） |

### 通过面板

插件卡片 →「查看页面」：

- **文件**：上方为类型栏，仅显示存在文件的类型；表格展示名称、类型、大小、版本、来源与更新时间，每行有「查看」「删除」两个按钮。点「查看」在表格下方展开预览：文本类直接显示正文，右上角可切换历史版本并下载该版本；Word、Excel、PPT、PDF、视频不显示正文，提示下载查看。

支持将文件拖拽到面板上传，或使用「上传」按钮选择文件；超过 8MB 的文件按分片上传。

## 模型工具

| 工具 | 说明 |
| --- | --- |
| `file_list` | 按类型、关键词、发送人或最近天数列出文件 |
| `file_read` | 读取文件内容，可指定历史版本；PDF 可指定页码，文本可指定行区间或关键词定位 |
| `file_write` | 修改文件内容：文本整体替换；Excel 按 `[{"sheet","cell","value"}]`、PPT 按 `[{"slide","shape","text"}]`、Word 按 `[{"paragraph","text"}]` 就地改写；改完回读确认 |
| `file_new` | 新建 Word/Excel/PPT/文本文件；或用 `from_id` 复制现有文件另存一份再改 |
| `file_send` | 将文件发送到当前会话 |
| `file_pdf` | PDF 操作：`keep` 保留指定页、`pages` 按页识图 |
| `file_video_link` | 解析视频链接并识别内容，可选择是否入库（需在配置中开启） |

## 数据目录

默认位置：`data/plugin_data/astrbot_plugin_file_rw_assistant/`

```
index.db                                      元数据（files / versions 表）
files/<会话>/<年-月>/<文件名>.<编号>.<扩展名>     当前版本
versions/<编号>/v<版本号>.<扩展名>               历史版本
temp/                                         抽帧、分片上传与导出临时文件
```

## 限制

- **消息平台发送能力**：QQ 需使用 NapCat 且当前会话允许上传文件；其他平台通过框架文件组件发送。平台不支持直发时仅提示文件位置，不产生错误、不丢失文件。
- **面板不改内容**：面板只做查看与下载；改写与新建一律通过模型工具 `file_write` / `file_new` 完成（文本、代码、CSV 可整篇替换，Office 就地改，PDF 只能按页操作）。
- **旧版 Office 格式**：`.doc`、`.xls`、`.ppt` 仅支持归档与下载，无法解析内容，也无法生成为这几种格式。
- **Office 就地改写**：仅修改已有单元格、形状、段落的文本，不支持新增行列、新增形状或插入图片。docx 的段落序号按「第 N 个非空段落」计；被改写的段落与形状会丢该段内部的局部格式（加粗、字号等），单元格只改值不动样式。
- **长文档读取**：单次读取默认截断在 8000 字；PDF 默认只看前 60 页，需要更后面用页码参数指定；Excel 与 CSV 默认前 200 行。
- **视频识别**：优先按场景切换抽关键帧（挑出的不够一半则退回全片均匀抽帧），帧数 = 时长 ÷ 抽帧间隔，夹在最小与最大帧数之间（默认 4 秒一帧、4～24 帧）；原声抽成音频一并送给模型（最多送开头 300 秒），内嵌字幕轨直接转文本送入。链接解析依赖 `yt-dlp`，部分平台需要配置 cookies，默认关闭。
- **不处理的格式**：压缩包、图片、音频不入库。
