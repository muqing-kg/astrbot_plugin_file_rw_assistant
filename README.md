# 文件读写小助手

AstrBot 插件：自动归档聊天中的文件，并向模型提供文件读取、修改、生成与发送能力，附带 Web 管理面板。

插件 ID：`astrbot_plugin_file_rw_assistant`

## 功能特性

- **自动入库**：群聊与私聊中收到的文件自动归档，保留原文件名，同名文件不覆盖。
- **版本管理**：每次改写生成新版本，可回滚，可设置版本数量上限。
- **内容读取**：文本、Markdown、代码、CSV 直接读取；Word、Excel、PPT、PDF 解析正文；扫描版 PDF 按页渲染后交视觉模型识别；视频按全片均匀抽帧识别。
- **内容修改**：文本整体替换；Excel、PPT、Word 就地改写并保留原有格式（列宽、公式、母版）；PDF 支持按页提取与正文重排。
- **文件生成**：根据模型输出创建新的文本类文件或 PDF。
- **发送回会话**：通过消息平台直接发送；平台不支持时提示文件位置。
- **Web 面板**：文件列表、类型筛选、内容预览、在线编辑、版本回滚、下载、发送、删除、分片上传。
- **自动清理**：按保留天数定时清理，超出上限的历史版本自动淘汰。

## 支持的文件类型

| 类别 | 扩展名 |
| --- | --- |
| Word | `.docx` `.doc` |
| Excel | `.xlsx` `.xls` |
| 演示文稿 | `.pptx` `.ppt` |
| PDF | `.pdf` |
| 文本 | `.txt` `.log` |
| Markdown | `.md` `.markdown` |
| 代码 | `.py` `.js` `.ts` `.json` `.yaml` `.yml` `.sh` `.sql` `.html` `.css` `.toml` `.ini` |
| 表格数据 | `.csv` `.tsv` |
| 视频 | `.mp4` `.mov` `.mkv` `.avi` `.webm` |

压缩包、图片、音频不在支持范围内。

## 环境要求

- AstrBot `>=4.16,<5`
- Python 依赖：`python-pptx`、`reportlab`、`pypdf`、`pypdfium2`、`yt-dlp`（由 `requirements.txt` 自动安装）
- 视频抽帧需要容器内可执行 `ffmpeg`

## 安装

1. 进入 AstrBot 面板 → 插件 → 从仓库安装，填入 `muqing-kg/astrbot_plugin_file_rw_assistant`。
2. 等待依赖安装完成。
3. 刷新插件列表完成加载。

依赖安装完成后需刷新一次插件列表；若依赖尚未就绪即加载，插件会因缺少模块而失败。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `retention_days` | int | `90` | 文件保留天数，`0` 表示永久保留 |
| `max_versions` | int | `20` | 单个文件的版本数量上限 |
| `max_file_mb` | int | `200` | 单个文件大小上限（MB） |
| `max_video_mb` | int | `2048` | 单个视频大小上限（MB） |
| `video_frames` | int | `8` | 视频抽帧数量 |
| `max_vision_images` | int | `6` | 单次识别提交的图片数量上限 |
| `auto_cleanup` | bool | `true` | 是否启用定时清理（每 6 小时一次） |
| `storage_root` | string | 空 | 文件存储根目录；留空使用插件数据目录 |
| `text_model_provider_id` | string | 空 | 文本处理使用的模型；留空跟随当前会话模型 |
| `vision_model_provider_id` | string | 空 | 图像与视频识别使用的模型；留空跟随当前会话模型 |
| `enable_pdf_ocr` | bool | `true` | PDF 无文字层时启用整页渲染识别 |
| `video_link_enabled` | bool | `true` | 是否允许解析视频链接 |
| `video_link_auto_delete` | bool | `true` | 链接解析下载的文件是否在用完后删除 |
| `video_link_cookies` | string | 空 | 需要登录的平台所用的 cookies 文件绝对路径 |

插件配置页与面板「设置」标签页读写同一份配置。

## 使用方式

### 通过聊天

收到文件后无需额外操作，插件自动归档并在当轮上下文中提供给模型。常见请求示例：

| 需求 | 示例说法 |
| --- | --- |
| 查找文件 | 「刚才那个表格在哪里」「列出全部 Excel」 |
| 读取内容 | 「这份 PDF 的主要内容是什么」 |
| 识别扫描件 | 「这张扫描件上写了什么」 |
| 修改单元格 | 「把 B2 的值改成 2024」 |
| 修改演示文稿 | 「第 2 页标题换一种说法」 |
| 修改文档 | 「删除第三段」 |
| 处理 PDF | 「只保留第 1 至 3 页」「按以下正文重排一份 PDF」 |
| 生成文件 | 「生成一份 Markdown 周报」 |
| 发送文件 | 「把这份文件发给我」 |
| 视频内容 | 「这个视频讲了什么」 |
| 视频链接 | 发送链接并询问「这个视频讲什么」 |
| 删除文件 | 在面板中操作（模型无删除权限） |

### 通过面板

插件卡片 →「查看页面」：

- **文件**：左侧为类型栏，仅显示存在文件的类型；右侧表格展示名称、类型、大小、版本、来源与更新时间。点击任意行打开详情抽屉，可预览内容、在线编辑文本、查看版本历史并回滚、下载、发送到会话、删除。
- **设置**：修改配置项，保存后立即生效。

支持将文件拖拽到面板上传，或使用「上传」按钮选择文件；超过 8MB 的文件按分片上传。

## 模型工具

| 工具 | 说明 |
| --- | --- |
| `file_list` | 按类型或关键词列出文件 |
| `file_read` | 读取文件内容，可指定历史版本 |
| `file_write` | 修改文件内容：文本整体替换；Excel 按 `[{"sheet","cell","value"}]`、PPT 按 `[{"slide","shape","text"}]`、Word 按 `[{"paragraph","text"}]` 就地改写 |
| `file_new` | 创建新的文本类文件 |
| `file_send` | 将文件发送到当前会话 |
| `file_pdf` | PDF 操作：`keep` 保留指定页、`pages` 按页识别、`rebuild` 按新正文重排 |
| `file_video_link` | 解析视频链接并识别内容，可选择是否入库 |

## 数据目录

默认位置：`data/plugin_data/astrbot_plugin_file_rw_assistant/`

```
index.db                                      元数据（files / versions 表）
files/<会话>/<年-月>/<文件名>.<编号>.<扩展名>     当前版本
versions/<编号>/v<版本号>.<扩展名>               历史版本
temp/                                         抽帧、分片上传与导出临时文件
```

若将 `storage_root` 配置为绝对路径，`files`、`versions`、`temp` 存放于该路径下，`index.db` 仍保留在插件数据目录。

## 限制

- **消息平台发送能力**：QQ 需使用 NapCat 且当前会话允许上传文件；其他平台通过框架文件组件发送。平台不支持直发时仅提示文件位置，不产生错误、不丢失文件。
- **在线编辑范围**：仅文本、Markdown、代码、CSV 支持在线编辑。Office 与 PDF 不支持在线编辑版式。
- **旧版 Office 格式**：`.doc`、`.xls`、`.ppt` 仅支持归档与下载，无法解析内容。
- **Office 就地改写**：仅修改已有单元格、形状、段落的文本，不支持新增行列、新增形状或插入图片。
- **PDF 重排**：仅保留文字内容，原版式、字体与图片不保留。
- **视频识别**：本地视频按全片均匀抽帧；链接解析依赖 `yt-dlp`，部分平台需要配置 cookies，解析失败时返回具体原因。
